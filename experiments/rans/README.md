# 2D 文脈モデル + rANS（実験）

```
node experiments/rans/encode.js   # -> experiments/rans/a
experiments/rans/iwiaa            # デコード
```

- モデル: 文脈 = 左の文字 + 真上（前の行の同じ桁）の文字、7 シンボルの適応頻度（初期値 1, +1）
- 符号: BigInt による無限精度 rANS。状態が 0 になったら終了するので長さ情報は持たない
- 末尾の改行は `console.log` が付ける

| | decoder | data | 合計 |
| --- | --- | --- | --- |
| v1.2.1（空白 RLE + Brotli） | 182 B | 840 B | **1022 B** |
| 本実験 | 283 B | 770 B | 1053 B |

データは 70 B 減るが、デコーダが 101 B 増えるため合計では 31 B 負け。
文字（`=+/#%`）の選択は近傍からほぼ予測できず（約 2.2 bit/文字）、データ側の下限は 750 B 前後と見られる。
